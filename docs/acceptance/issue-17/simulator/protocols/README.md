# 模拟器运行协议快照

本目录用于审计实际调用，依赖本地忽略配置与当时的夹具；清理后旧 ID 不能直接执行。[源码/发布 SHA](sources.json)仅记录路径脱敏转换。

- `attach-runtime.py`：针对两个本轮专用 AVD；读取已验证 Metro 的实际源码/回传配置，短时绑定证明端口，强制冷启动目标 App，要求真实包名回传。共享 Metro 标识不冒充新启动的 Metro；其他 AVD 不得同时映射该证明端口。没有设置假回传或跳过运行证明。
- `oauth-login.py`、`browser.mjs`：各自本地 Chrome，仅处理 localhost 登录/授权页，用实际 App 令牌读回账号；不复制手机登录状态，密码与令牌不输出或落盘。
- `run.py`、`http-checks.py`：UI 计划后读真实 HTTP；冷启动必须有前后 PID 与源码/设备匹配证据，避免把切宠读回称为重进。
- `finalize.py`：只用内存中的实际 App OAuth 令牌完成访客、团队删除和精确清理。清理前后核对原 U1 记录哈希与照片字节，撤销 U2 测试令牌及精确的 U1 模拟器令牌，验证 U1 其他两个会话不变。
- `cleanup-local.php`：校验新账号 ID、用户名、创建时间；举报/物种申请有精确 ID、账号和标记约束；技术角色仅降权并撤销令牌。原 U1 令牌按 jti、用户和客户端匹配，不全量注销主人账号。

模拟器包由旧 x86 原生包仅更新当前本地配置资产后对齐/调试重签；[来源证明](../apk-config-provenance.json)验证 28 个原生库及 1,970 个其他条目未变。没有将配置重签描述为完整原生编译。

正文/标题/关联宠物/照片组合复验的夹具照片通过 API 恢复，明确属于准备，不计 App 上传；实际四次相册上传证据在真机阶段。首轮照片读回失败与严格组合通过都保留，未据此宣称改动产品照片删除逻辑。
