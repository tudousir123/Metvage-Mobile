## 设计来源和采用方式

视觉方向为[已归档的七张用户原图及边界说明](https://github.com/tudousir123/Metvage/blob/codex/metvage-v1/docs/design/metvage-ui-alignment-2026-11-03.md)：暖白底、墨绿、珊瑚橙、真实照片、紧凑信息层级和圆角卡片。原图没有专门的搜索/公开档案稿，本轮沿用首页照片卡片及宠物主页的视觉语言，没有增加原型中的等级、品种、年龄或陪伴天数。

本轮重新查看了 [React Native Reusables](https://github.com/founded-labs/react-native-reusables) 与 [Tamagui](https://github.com/tamagui/tamagui)。参考前者清楚的输入/按钮层级，沿用项目既有 Tamagui/React Native 栈；没有复制库源码，也没有引入 NativeWind 或另一套主题。Expo 52 不适用新版 `@expo/ui`，因此保留当前原生控件。

服务端没有独立宠物头像字段。公开档案头像取该宠物可公开读取的记录照片；搜索只使用本次公开结果中已有照片，无照片使用爪印占位。不会为头像请求私人照片，或虚构头像资料。

## 环境和边界

- 实体 Xiaomi 14 Ultra，型号 `24031PN0DC`，Android 16 / API 36；1440×3200、560 dpi、系统字体倍率 1.45。保持用户原有字体和输入法，没有改分辨率或密度。
- 复用独立测试 App `com.metvage.acceptance.phone` 和已有测试登录；未清除数据或重装 APK。实际从本工作区启动 Metro，`doctor` 校验 Git SHA、分支、入口、依赖路径和进程目录；本地使用 Node 24.22.0，GitHub CI 使用仓库指定的 Node 20。
- 本地真实 Server 使用原有 SQLite/Redis，API 为 loopback `18080`。只在独立测试账号上创建带本轮标记的临时素材和评论；API 令牌仅存在进程内存中，退出时撤销。
- 所有设备点击/截图走版本化验收工具的设备锁、前台检查和恢复日志。系统亮屏值恢复为原来的 `2`，字体仍为 `1.45`。保留开发服务和原有测试会话，便于继续查看。
- 同名标签缺少 index 的计划停止；一次重启在 Metro 准备好之前出现无法加载脚本；一次连续返回计划退出了测试 App。均保留失败记录，修正计划/启动时序后重新执行；失败尝试不计为通过。
- iOS、其他输入法、新安装/正式签名 APK、真实运营网络丢包、修改密码和删除账号不在本轮覆盖范围。法律正文仍由 [#31](https://github.com/tudousir123/Metvage/issues/31) 跟踪，本轮不将法律入口可用视为正文确认。
